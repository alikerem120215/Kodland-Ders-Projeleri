# 🎓 Kodland Ders İçi Projeler Arşivi

Bu depo, **Kodland** ileri düzey yazılım eğitimleri süresince geliştirilmiş Python, Flask, Yapay Zeka ve Web teknolojilerini kapsayan modüler ders projelerini barındırır.

---

## 📁 Modüller ve İçerikler

### 1. `M7L3` — Çok Dilli Çeviri Motoru (Translator Engine)
- Python, Flask ve Google Translate API entegrasyonu.
- Metinleri otomatik dil algılama ile anlık farklı dillere çeviren web arayüzü.

### 2. `M7L4` — Yapay Zekalı Dil Öğrenme Asistanı
- Google Gemini API ve ses işleme (`sounddevice`, `speech_recognition`) entegrasyonu.
- Telaffuz analizi ve interaktif konuşma pratiği yaptıran AI eğitmen.

### 3. `M8L2` — Bot & Veri Depolama Altyapısı
- Python ile veri tabanı yönetimi ve bot akışları uygulaması.

### 4. `M9L1` — HTML5 Ses Kaydedici & İndirici (Audio Recorder Utility)
- Tarayıcı üzerinden mikrofon sesini yakalayan, dalga formunu gösteren ve yerel sunucuya kaydeden modern web aracı.

---

## 🚀 Kurulum
Her modülün kendi bağımsız dizinine girip ilgili sanal ortamı kurarak çalıştırabilirsiniz:
```bash
cd M7L4
pip install -r requirements.txt
python3 app.py
```
